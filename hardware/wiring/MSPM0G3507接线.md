# MSPM0G3507 接线方案 v2

当前使用板载 CH340 USB 串口完成下载和调试。ST-Link 路线尚未验证目标连接，见 [专项说明](../../docs/testing/STLink接线与检测.md)。

本表对应 `firmware/keil/robot_mspm0.uvprojx`，主控已由 STM32 改为 **TI MSPM0G3507**。原图中的 STM32 引脚和 ST-Link 设置不能照搬。

2026-11-01 已收到实物正面照片：中间为核心板，外围为扩展板，电源输入丝印为 **IN 5–12V**，另有 OUT；没有可确认的完整板型或电源原理图。板上 `A10` 等丝印对应代码 `PA10`（GPIO 名，不是封装第 10 脚）。白色插座含不同信号和电源排列，不能统一按从左到右的针序接线。

**当前只需核心板 USB-C 接电脑，无需另接下载线或 TX/RX。** UART0 / A10、A11 已通过板载串口实测。照片不能确认所有扩展插座的内部连接，后续 PA18、PA15/16 仍需核对板载占用。

## 1. 信号接线

| 用途 | MSPM0G3507 | 接另一端 | 参数 |
|---|---|---|---|
| K230 发送识别结果 | **PA18 / UART1_RX** | K230 **GPIO9 / TX** | 115200、8N1、3.3V TTL |
| 预留给 K230 的发送线 | **PA17 / UART1_TX** | K230 **GPIO10 / RX** | 当前程序不发控制消息，可暂不接 |
| 视觉共地 | GND | K230 GND | 必接 |
| 机械臂总线发送 | **PA21 / UART2_TX** | BusLinker 的主控侧 **RX** | 115200、8N1 |
| 机械臂总线接收 | **PA22 / UART2_RX** | BusLinker 的主控侧 **TX** | 返回信号必须满足 3.3V 逻辑 |
| 总线共地 | GND | BusLinker GND | 必接 |
| 云台水平信号 | **PA15 / TIMA1_CCP0** | 水平 PWM 舵机 S | 50Hz，初始不输出 |
| 云台俯仰信号 | **PA16 / TIMA1_CCP1** | 俯仰 PWM 舵机 S | 50Hz，初始不输出 |
| 调试输出 | **PA10 / UART0_TX** | USB-TTL RX | 115200、8N1、3.3V TTL |
| 调试输入 | **PA11 / UART0_RX** | USB-TTL TX | 输入英文命令，CRLF 结尾 |
| 调试共地 | GND | USB-TTL GND | MCU 已供电时通常只接 TX/RX/GND |

两路通信都是 UART，原流程图里 K230 与主控之间的 **I²C 改为 UART**。GPIO9/10 来自亚博该系列通信口资料，K230 实物版本仍需核对。不要把 K230 的电源 5V 脚当成信号脚。

BusLinker 必须是支持 **HTD-35H / HTS-21H 传统 115200 协议**的型号，且主控侧串口电平适合 MSPM0。不同版本接口命名/接法可能不同；上述 RX/TX 按“转换板自身接收/发送”定义，必须对照厂家接口图。不要把 MCU 的 TX、RX 直接短接后连到舵机单线信号，也不要用 RS232 电平串口。

机械臂四个总线舵机在 **转换板的舵机侧**并联/串接信号与电源。三个 HTD-35H 和一个 HTS-21H 都不是普通 PWM 舵机。计划 ID：底座 1、肩关节 2、肘关节 3、夹爪 4；仅为建议，程序没有自动改 ID。厂家默认 ID 通常相同，要单独接入逐个设置，确认后才能一起挂总线。

## 2. 供电

```text
12V 电池（确认满充电压）
  ├─ 合适的电源支路 → 幻尔总线转换板/舵机电源 → 3×HTD-35H + 1×HTS-21H
  ├─ 合适的降压模块 → 云台舵机额定电压 → 两个 PWM 舵机
  └─ 经确认的逻辑电源 → MSPM0 主控板、K230 各自规定的供电入口

所有信号地共地；舵机的大电流回路直接回电源分配点，避免经过主控小排针。
```

- **12V 不能接 MSPM0 的 3V3、5V 或任何信号脚，也不能直接接 K230 的 5V 输入。** 今天不带舵机调试时，两板可各用自身规定的 USB 供电，再连接信号和 GND；不要额外把两块板的电源正端相连。
- HTD-35H、HTS-21H 官网标称工作电压为 9–12.6V；这不能证明扩展板的“OUT”端也是这个电压或能承受电流。原图把扩展板 OUT 接到机械臂供电的部分，必须先确认 OUT 电压、最大电流、接插件能力。
- 官网列出 HTD-35H 堵转电流约 3A、HTS-21H 约 1A，四个合计约 10A 的堵转量级。电池的 6000mAh 表示容量，不代表允许输出电流；电源、线材、保险和开关应按实际峰值及厂家要求选择。
- 云台标“25kg”通常是扭矩等级，无法据此确认电压、脉宽或堵转电流。图中的 6V 只有在具体舵机支持时才能使用；MP2491C 模块是否带得动两台，需要其模块规格及散热条件，不能只看芯片名称。
- 停止 PWM 或发送总线 STOP 都不等同于切断电源；以后带机械臂测试要有可直接切断舵机动力的开关。默认程序不使能动作。
