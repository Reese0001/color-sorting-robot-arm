# 颜色分拣机械臂

K230 识别红 / 绿 / 蓝三色木块，把坐标通过串口发给 STM32F103C8T6，
由 STM32 决策并驱动机械臂夹取，按 **红左 / 绿中 / 蓝右** 的顺序排列。

摄像头与云台加固在机械臂夹爪上（一体式），会随机械臂一起运动。

## 快速开始

### K230 端

1. `vision/k230/camera_check.py` —— 确认相机正常，终端打印 `Camera OK`
2. `vision/k230/auto_calibrate.py` —— 按屏幕提示放入红绿蓝木块，自动标定阈值
3. 把输出的三行阈值粘进 `color_detection.py` 的 `COLOR_THRESHOLDS`
4. `vision/k230/color_detection.py` —— 跑识别

详细步骤、调参口诀、接线说明见 [`vision/k230/README.md`](vision/k230/README.md)。

### STM32 端

把 `firmware/lib/k230_protocol/` 当作私有库引入，`#include "k230_protocol.h"` 即可。
接入方法、USART2 初始化代码、状态机框架见
[`firmware/lib/k230_protocol/README.md`](firmware/lib/k230_protocol/README.md)。

## 通信协议速览

K230 每 100 ms 发一帧 ASCII 文本，三色各占一个槽位：

```text
@T,seq,pan,tilt,rx,ry,rp,gx,gy,gp,bx,by,bp*XX\r\n
```

示例（三色都在）：

```text
@T,42,90,90,320,240,5120,180,260,4800,150,300,4300*52\r\n
```

某色没看到就填 `-1,-1,0`。校验是对 `T` 到 `*` 之前所有字节做 XOR。

**分工原则：K230 只回答"看到什么"，STM32 决定"夹哪块"。**

完整规范见 [`docs/通信协议.md`](docs/通信协议.md)，包含字段定义、校验算法、
STM32 四层接收流程的完整 C 代码、故障对照表。

## 抓取决策

STM32 侧按顺序判断：

1. 只有一种颜色有效 → 直接夹它
2. 多种颜色有效 → 夹像素数最大的（最靠近 / 最正对）
3. 像素数差距在 5% 以内（分不出谁最大）→ 按 **红 > 绿 > 蓝**

第 3 条是为了压住抖动：两块木块一样大时，像素数的正常波动会让"最大的那个"每帧跳变，
机械臂跟着左右摇摆。容差比例在 `k230_protocol.h` 的 `K230_TIE_RATIO`。
