# 颜色分拣机械臂：目录与代码存放规范

项目根目录：D:\DevProject\robot1

当前视觉方案为 K230。本次仅建立目录骨架和规范，不新增业务代码。远程仓库仅上传目录占位文件和本规范。

## 目录用途

| 相对路径 | 存放内容 |
| --- | --- |
| firmware/src/ | STM32 主控程序：入口、机械臂动作、通信处理等 .c/.cpp 源文件 |
| firmware/include/ | 主控公共头文件、模块接口和配置声明 |
| firmware/lib/ | 项目自有的独立驱动或可复用模块，每个模块一个子目录 |
| vision/k230/ | K230 视觉程序：颜色识别、目标定位、结果发送；具体运行环境确定后再组织内部模块 |
| hardware/schematics/ | 电路原理图及导出文件 |
| hardware/wiring/ | 接线表、引脚分配和接线图片 |
| hardware/mechanical/ | 机械结构图、尺寸及模型文件 |
| tools/ | 电脑端串口调试、数据分析等辅助脚本 |
| tests/ | 可在电脑上执行的协议、算法等测试代码 |
| docs/ | 项目说明、通信协议、开发记录 |
| docs/calibration/ | 颜色、坐标、舵机等标定步骤和记录 |
| docs/testing/ | 测试步骤、测试结果和硬件验证记录 |

## 代码存放规则

1. STM32 代码放在 firmware/；K230 代码放在 vision/k230/；电脑辅助程序放在 tools/。不要在项目根目录散放业务代码。
2. 文件和目录采用英文小写及下划线，例如 color_detection.py、arm_control.cpp。沿用已有构建入口，迁移前先更新构建配置和引用。
3. 主控公共接口放在 firmware/include/；模块内部头文件可与源文件放在一起。项目自有独立模块放在 firmware/lib/<模块名>/，第三方依赖优先由构建工具管理。
4. 原理图、图片、模型和说明文档不放入代码目录。测试记录注明日期、硬件型号、软件版本和实际结果。
5. .pio/ 等构建产物由工具生成，不手动存放源代码。密钥、密码和个人配置不得写入项目代码。
6. platformio.ini 保留在根目录，当前源代码路径为 firmware/src，公共头文件路径为 firmware/include。
