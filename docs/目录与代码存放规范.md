# 项目目录与板卡对应关系

| 工程 | 源码 | 调试入口 |
| --- | --- | --- |
| G3519 课堂调试 | `firmware/g3519_wiring_test/` | [手册](../output/pdf/Robot1机械臂同学调试手册.pdf)、[固件及排针图](../output/mspm0g3519/) |
| K230 摄像头 | `vision/k230/` | [五色识别](../vision/k230/README.md)、[旧台架串口协议](../vision/k230/README_G3507_bench.md) |
| G3507 固定点 V1 | `firmware/mspm0/` | [固定点分拣](../README_G3507_V1.md) |
| G3507 台架 v2.1 | `firmware/keil/`、`firmware/src/*.c`、`firmware/include/`、`firmware/lib/` | [台架代码导航](代码导航.md) |
| STM32 / OpenMV | `firmware/src/*.cpp`、`openmv/`、`platformio.ini` | [早期说明](archive/readme_openmv.md) |

`hardware/` 存放硬件照片与按板型编写的接线说明，`tools/` 存放电脑端工具，`tests/` 存放离线测试。Keil 工程和课堂资源包按相对路径查找文件。更新目录时同步检查构建入口与手册链接。

`output/` 保存可分发固件、讲义和标定记录；`dist/` 对外提供课堂资源包。构建缓存、驱动备份、串口日志和本地认证状态由 `.gitignore` 排除。`build/sdk_overlay/` 保存本项目编译用的 TI 补充头文件。
