# 第一版接线教程

> PWM 接口更新：J1 改为 B18/PB18（TIMA1 CCP1），J2 改为 B19/PB19（TIMG8 CCP1），两路均为 50Hz。必须使用此配置重新烧录的固件；原 B08/B09 接法停用。

> 2026-11-13 修订：依据用户实物照片，电脑调试 UART 已改为 **UART3：PA14 TX / PA13 RX**。照片未见 PA10/PA11 的外部引出，旧接法停止使用。必须重新烧录本次生成的 `build/mspm0/robot1.out` 或 `robot1.hex` 后，A14/A13 接法才生效。

## 按实物丝印逐根接线

准备：拔掉 USB 和全部动力电源后接线；机械臂有支撑。下表的 `A14`、`B18` 是实物丝印，分别等于 PA14、PB18。只按丝印找针，不按线颜色猜引脚。白色多针插座不是通用舵机插口，不要直接把三针舵机插进去。

### 电脑 USB-TTL（独立调试适配器）

| USB-TTL 端 | 扩展板丝印 | 含义 |
| --- | --- | --- |
| RXD | A14 | MCU UART3 TX → 电脑 |
| TXD | A13 | 电脑 → MCU UART3 RX |
| GND | GND | 共地 |
| VCC / 5V / 3V3 | 不接 | MCU 首轮单独通过核心板 USB 供电 |

以照片中核心板 Type-C 在右边为参照：A14 在上排针靠近右端、5V 旁；A13 在下排针靠近右端、A12 旁。最终以对应针脚丝印为准，避免错插到邻近的 5V。TTL 的 TX 信号高电平必须是 3.3V；有些适配器的 3.3V/5V 跳帽只改变供电脚，需核实具体型号或测量信号电平。串口设为 115200、8N1、无流控。

### K230 与 MSPM0（UART）

| K230 端 | 扩展板丝印 | 信号方向 |
| --- | --- | --- |
| IO9（UART1 TX） | A22（UART2 RX） | K230 → 主控 |
| IO10（UART1 RX） | A21（UART2 TX） | 主控 → K230 |
| GND | GND | 共地 |

K230 使用配套 5V Type-C 电源；两板之间先只接上表三根线，不连接两板的 5V/3V3。A21/A22 位于照片上排针中部。两端均为 3.3V UART，115200、8N1。K230 的 UART1 与主控的 UART2 是各自芯片上的端口编号，可以相互通信。K230 程序需要同目录的 `robot_link.py`，联调时启用 `UART_ENABLED=True`；颜色校准状态仍按实测设置。

### 两只 PWM 舵机

| 舵机 | 信号 S | 电源正极 | 电源负极 |
| --- | --- | --- | --- |
| J1 底座，20 kg·cm | B18（PB18） | 独立稳压 6.0V 的 + | 同一 6.0V 电源的 − |
| J2 第一俯仰关节，25 kg·cm | B19（PB19） | 独立稳压 6.0V 的 + | 同一 6.0V 电源的 − |

B18/B19 在照片上排针中部，靠近 A18、A21；按对应针脚丝印确认。将舵机插头通过转接线拆分出 S、+、− 三路；典型配色为黄/橙=S、红=+、棕/黑=−，仍需核对舵机实际线序。6.0V 电源负极再连接扩展板 GND。两个舵机可用同一独立 6.0V 电源，但电源、接头、线材须能承受两只舵机同时启动和带载的电流；当前未核实具体容量。

**不能将舵机红线接扩展板 5V、3V3 或 USB-TTL 电源脚。** 照片上的 `IN 5–12V`、`OUT` 端子及板载调压器尚未核实电路和带载能力，本接法使用独立 6.0V 支路；不以这些端子替代。接舵机前，用万用表确认输出为 6.0V 并确认正负极；3S 电池原电压不能直接给这两只 PWM 舵机。

### BusLinker V2.5 与三只总线舵机

| 扩展板丝印 | BusLinker UART 端 | 作用 |
| --- | --- | --- |
| B06（PB6，TX） | RX | 主控发送指令 |
| B07（PB7，RX） | TX | 主控接收反馈 |
| GND | GND | 共地 |

这两根信号线**以电平匹配为接通前提**：BusLinker TX 电平目前未确认；若为 5V，必须经适合 115200 UART 的电平转换接 B07，且 PB6 的 3.3V 高电平须满足 BusLinker RX 门限。不要将 5V TX 直接接 B07。BusLinker 的 UART 5V 脚不接扩展板。

三只总线舵机连接 BusLinker 的专用三针总线口，按板上电源、GND、信号标注和配套线序插接：J3 HTD-35H 设 ID1；J4 HTD-35H 设 ID2；J5 HTS-21H 夹爪设 ID3。它们共用总线，无需各占一个 MCU 引脚。设 ID 时一次接一只。BusLinker 动力输入 VIN/+ 接匹配三只舵机额定范围的独立 9～12.6V 电源正极，GND/− 接负极；实测不得超过额定上限。此正极不可与 PWM 6.0V 正极相连。MCU 接管前拔掉 BusLinker USB，避免两个发送端同时驱动串口。

### 电源与首次检查

```text
K230 配套 5V 电源 ─── K230 Type-C
电脑 USB ─────────── MSPM0 核心板 Type-C
独立稳压 6.0V + ─── 两只 PWM 舵机 +
总线舵机额定电源 + ─ BusLinker VIN/+ ─ 总线舵机

K230 GND、MSPM0 GND、TTL GND、6.0V −、BusLinker GND 共地
```

1. 舵机动力断开，用兼容 MSPM0 的 SWD 下载器烧录本次固件；普通 USB-TTL 只用于通信，不能替代本流程的 SWD 下载器。
2. 只给主控和 USB-TTL 上电，查看启动 `ROBOT1 V1 DISARMED`，发送 `HELP`、`STATUS`，先确认双向串口可用。无需发送 ARM。
3. 按接线表连接并运行 K230，核对串口通信；视觉确认后再启用已校准标志。
4. 核实 BusLinker 电平及动力极性，再接通总线舵机，只读取状态。两只 PWM 舵机动力仍保持断开。
5. PWM 舵机先卸载连杆或拆开舵盘与负载的连接、支撑机械结构；确认 6.0V 后再单只测试，按 `testing_v1.md` 核实起始脉宽、方向及机械限位。不得直接套用通用 1500µs 或别人的起始角度。
6. PA2/A02 与 GND 可接一个常开停止按钮，先用串口验证按下后触发停止。照片上的 K1 是否连到 PA2 尚待导通测试，不凭按钮名称认定。STOP 是软件停止，需保留能直接切断舵机动力的开关。

本次已验证芯片引脚复用和固件编译；照片不能证明扩展板内部接线、电源承载或实物通信已通过。VL53L0X 暂不包含在本接线表中，需在确认模块供电和可用 I²C 引脚后单独接入。

适用硬件：MSPM0G3507 LQFP64 核心板及照片中的扩展板、亚博 K230 豪华版、BusLinker V2.5、HTD-35H ×2、HTS-21H ×1、亚博 20 kg·cm 和 25 kg·cm PWM 舵机。
下面是新固件 `firmware/mspm0/robot.syscfg` 的引脚分配，已经通过 TI SysConfig 检查。它不沿用小车工程的接线占用；连接前移除这些引脚上的旧模块。

## 1 关节编号

| 编号 | 机械位置 | 控制形式 | 程序使用的单位 |
| --- | --- | --- | --- |
| J1 | 底座转向，亚博 20 kg·cm | PB18 PWM | 微秒 |
| J2 | 第一个俯仰关节，亚博 25 kg·cm | PB19 PWM | 微秒 |
| J3 | 上部靠近 J2 的 HTD-35H | 总线 ID 1 | 舵机位置单位 0～1000 |
| J4 | 上部靠近夹爪的 HTD-35H | 总线 ID 2 | 舵机位置单位 0～1000 |
| J5 | HTS-21H 夹爪 | 总线 ID 3 | 舵机位置单位 0～1000 |

ID 1/2/3 是本项目要求分配的值，不是对当前舵机 ID 的判断。首次设置时一次只连接一只总线舵机，使用 BusServoTerminal 读出旧 ID 后设置新 ID；再逐个复核。所有总线舵机必须设为位置/舵机模式，不使用连续旋转的电机模式，并启用舵机控制。总线位置单位不是角度，第一版直接使用原始单位示教。

## 2 先接逻辑信号

全部断电后接线。表中 TX/RX 是各设备自身的发送/接收端；按丝印和实际板版次确认，不按杜邦线颜色猜信号。

| MSPM0 端 | 对端 | 作用 |
| --- | --- | --- |
| PA22，UART2 RX | K230 IO9，UART1 TX | 接收识别帧 |
| PA21，UART2 TX | K230 IO10，UART1 RX | 发送观察批次号 |
| PB6，UART1 TX | BusLinker 的 UART RX | 发送总线舵机协议 |
| PB7，UART1 RX | BusLinker 的 UART TX | 读取位置反馈 |
| PB18，TIMA1 CCP1 | J1 舵机信号 S | 底座 PWM |
| PB19，TIMG8 CCP1 | J2 舵机信号 S | 第一关节 PWM |
| PA14，UART3 TX | USB 转串口适配器 RX | 电脑接收状态 |
| PA13，UART3 RX | USB 转串口适配器 TX | 电脑发送调试命令 |
| GND | K230、BusLinker、两只 PWM 舵机及串口适配器 GND | 公共参考地 |
| PA2/K1 | 扩展板 K1，按下接地 | 软件停止输入 |

三个串口都是 115200、8 数据位、无校验、1 停止位。不要把 K230 的端口名 UART1 与 MSPM0 的 UART1 混为一个硬件端口。
K1 使用上拉、低电平有效；接线后先按测试教程验证按键是否确实接到 PA2。如果板卡版次不同，可在 PA2 与 GND 之间接独立常开按钮。

MSPM0/K230 的 GPIO 按 3.3V 逻辑连接。USB-TTL 适配器应设为 3.3V 逻辑。BusLinker V2.5 的照片能确认接口丝印，但不能确认 TX 高电平电压：先测量或查本板原理图；若输出为 5V，PB7 前必须加入适合 115200 UART 的 5V→3.3V 电平转换，PB6→RX 也应满足其输入门限。未确认时按需要电平转换接法准备，不把 5V 信号直接接 MCU。不要套用 BusLinker V3 的引脚/协议说明。

初次联调时 BusLinker 的 USB 用于单独配置舵机；切换 MCU 控制后拔掉 BusLinker USB，避免电脑串口与 MCU 同时驱动同一总线。电脑调试使用另一只 USB-TTL。

## 3 电源分开供给

| 负载 | 第一版供电接法 | 禁止混接 |
| --- | --- | --- |
| K230 | 按配套说明通过 Type-C 使用稳定 5V 电源 | 不接 6V 或原电池电压 |
| MSPM0 | 初次使用核心板 USB 供电；扩展板外部电源保持断开 | 不同时从未核实的多个入口反向供电 |
| 两只亚博 PWM 舵机 | 独立、满足实际启动和负载电流的稳压 6.0V 支路 | 不接 3S 电池原电压，不从 MCU 的 5V 引脚取动力电 |
| 三只高压总线舵机 | 合适的 9～12.6V 电源 → BusLinker VIN/GND → 舵机 3Pin 总线 | 不把总线 VIN 接到 K230 或 PWM 舵机 |

你照片中两只 PWM 舵机标有 DC 6～7.4V，因此首轮采用 6.0V。HTD-35H 和 HTS-21H 的厂家资料给出 9～12.6V；采用 3S 电池时须实测端电压且不能超过 12.6V。
公共地相连不等于正电源相连。BusLinker 的 `5V` 串口脚本方案不接；它不能作为整机电源汇合点。

多路电源板的接口标签不能证明各路可承受两只大扭矩舵机的峰值电流。先空载测量，再做带载电压检查；未完成之前，不把整机所有电源都交给这块板。初次保持机械臂有支撑，准备直接切断舵机动力电源。

## 4 下载接口

| MSPM0 | 与芯片兼容的 SWD 下载器 |
| --- | --- |
| PA19 | SWDIO |
| PA20 | SWCLK |
| GND | GND |
| 3.3V 参考电压 | VTREF，具体按下载器说明 |
| RST，若下载器需要 | nRESET |

本机可用的流程是 TI UniFlash/CCS 配合支持 MSPM0G3507 的探针，例如 XDS110。核心板 USB 插座不等于板载 XDS110；普通 USB-TTL 不是 SWD 下载器。不要照旧 STM32 的 ST-LINK/PlatformIO 教程烧录这份固件。

## 5 接线后的检查顺序

1. 所有舵机动力电源断开，仅接 MCU，确认串口启动信息是 `ROBOT1 V1 DISARMED`。
2. 在 PB18/PB19 测量：上电未发送 ARM 时没有周期 PWM 输出。
3. K230 单独运行并标定，再接三根通信线和公共地。
4. 单独配置三只总线舵机 ID，串联后接 BusLinker；只做位置读取，确认 `STATUS` 的 `online=1`。
5. 机械臂支撑好，两只 PWM 舵机先卸载连杆，核对方向和脉宽；按测试教程发送 ARM。
6. 分关节小步调试，再装回、示教、执行完整空载流程，最后加入方块。

`STOP`/K1 是软件停止：停止后保留 PWM，向总线舵机发送停止指令，不主动卸力，以免承重关节下坠。它不是动力隔离急停；掉电或看门狗复位时 PWM 会停止，结构仍需支撑。
