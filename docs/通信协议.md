# 项目通信协议 v1.3

主控为 **MSPM0G3507**，不再是 STM32F103。K230 的 `@T` 数据格式保持兼容，主控引脚改为 PA17/PA18。以下以本次 `firmware/keil/robot_mspm0.uvprojx` 为准。

## 1. K230 → 主控：三色观测数据

UART，**115200、8 数据位、无校验、1 停止位、无流控、3.3V TTL**。建议每 100ms 发一帧。当前 K230 脚本仍是 `UART_ENABLED=False`，本次没有替你开启它或改动相机程序。

```text
@T,seq,pan,tilt,rx,ry,rp,gx,gy,gp,bx,by,bp*XX\r\n
```

`\r\n` 代表实际回车换行两个字节，不是四个可见字符。

| 字段 | 范围/含义 |
|---|---|
| T | 固定帧类型，必须正好是 `T` |
| seq | 0–65535，发送端逐帧递增并回绕；接收端保存供诊断，尚未做重复序号过滤或重传 |
| pan、tilt | 0–180，视觉端填入的角度字段；当前脚本固定 90，**不等于实际云台反馈** |
| rx、ry、rp | 红色目标中心 x、中心 y、像素数量 |
| gx、gy、gp | 绿色目标，同上 |
| bx、by、bp | 蓝色目标，同上 |
| XX | 对 `T` 到 `*` 前最后一个字节逐字节 XOR，编码为两位十六进制 |

画面固定为 640×480，x=0–639、y=0–479、像素数=1–307200。左上角为 (0,0)。某颜色没有稳定目标时，该组三个字段必须为 **`-1,-1,0`**；不接受不一致的组合。

例子（三色都有）：

```text
@T,42,90,90,320,240,5120,180,260,4800,150,300,4300*52\r\n
```

主控接收流程：UART1 中断入队 → 主循环按帧解析 → 检查 XOR、字段数、十进制和范围 → 整帧通过才替换观测数据。坏帧不会刷新在线时间；上电没有收到合法帧时离线；500ms 无合法帧即离线。串口错误或缓冲溢出时丢弃受影响的缓冲、取消在线状态，等待下一帧恢复。接收端也允许仅 LF 结尾及小写十六进制校验。

`K230_PickTarget()` 按最大像素数选择；其他颜色像素数达到最大值 95% 时，以红、绿、蓝顺序破同分。像素数不是距离，不能由此认定哪个物体最近。这个函数目前只用于显示候选目标，**不会触发机械臂动作**。

当前没有主控→K230 的 ACK、运动命令或角度反馈协议，PA17 发送线预留。重传、观察姿态编号、运动完成握手和抓取坐标变换留待机械结构/标定确定后设计。

## 2. 主控 → 幻尔总线转换板 → 舵机

UART2，115200、8N1。采用幻尔传统单线半双工舵机协议，转换板负责电气转换；不是直接把 UART TX/RX 短接到舵机信号。

```text
55 55 ID LEN CMD PARAM... CHECKSUM
LEN = 参数字节数 + 3
CHECKSUM = ~(ID + LEN + CMD + 所有参数) & 0xFF
```

| 功能 | CMD | 参数 |
|---|---|---|
| 指定时间转动 | 1 | 位置 uint16 小端、时间 ms uint16 小端 |
| 停止转动 | 12 | 无 |
| 读当前位置 | 28 / 0x1C | 请求无参数；回复带两字节位置 |

协议位置范围 0–1000，对应标称 0–240°；时间协议范围 0–30000ms。真实机械臂关节限位通常更窄，必须逐个标定。不会发送广播、修改 ID、写 EEPROM 或解除扭矩的命令。

ID=1、位置=500、时间=1000ms 的构帧测试向量（**当前并未发送**）：

```text
55 55 01 07 01 F4 01 E8 03 16
```

读取 ID=1 位置：`55 55 01 03 1C DF`。接收器验证长度和校验；`READ` 仅接受对应 ID/命令且参数长度为 2 的回复，100ms 没回复报告超时。转换板回显的无参数请求不会被误认为位置反馈。

此驱动根据[厂家总线协议](https://engineering.purdue.edu/477grp4/Team/journal/img%20-%20Juho/week7/servo%20bus%20protocol.pdf)准备；用户网盘内说明书正文尚未读取。实际转换板版本待核对，`BUS_PROTOCOL_CONFIRMED=0` 默认禁止发送总线报文。

## 3. 电脑 → 主控：调试串口

UART0，PA10=TX、PA11=RX，115200、8N1。命令区分大小写，以换行结束。上电打印版本，之后每秒输出 `STATUS`。

| 命令 | 作用 |
|---|---|
| `HELP` | 查看命令 |
| `PING` | 返回 `PONG MSPM0G3507` |
| `STATUS` | 在线状态、帧序号、候选颜色、成功/失败/丢数据计数、动作开关 |
| `ARM` | 仅在配置允许动作时开启 10 秒手动测试窗口；本身不运动 |
| `DISARM` | 停止 PWM；对本次已运动 ID 发 STOP，不卸力，不等同于断电 |
| `PWM 1500 1500` | 两路脉宽，单位 µs；默认锁定；启用后仍须满足 1000–2000µs 的临时测试范围 |
| `READ 1` | 读舵机位置；须先确认并启用总线协议；不要求 ARM |
| `MOVE 1 500 1000` | 单舵机测试；须同时启用动作、总线并 ARM |
| `START RED` / `START GREEN` / `START BLUE` | 开始七步纯模拟流程，不输出硬件动作 |
| `PAUSE` / `RESUME` / `STOP` / `RESET` | 模拟流程的暂停、继续、中止、复位；STOP 不是物理急停 |
| `FLOW` / `JOINTS` / `POSES` | 查看演练状态、关节表、姿态表 |
| `SIM AUTO` / `SIM MANUAL` | 空闲时选择自动或手动模拟回执 |
| `ACK ticket` | 手动模式确认当前步骤；不接受旧 ticket |
| `SIM STALL` / `SIM FAIL` | 注入模拟超时 / 模拟失败 |

手动 MOVE 暂只允许 ID 1–4、位置 450–550、时间 500–3000ms。它们是程序的保守测试限制，**不是已确认的机械安全范围**，启用前必须根据实物修改。10 秒没有 ARM 或成功动作命令续期会 DISARM。默认 `MOTION_OUTPUT_ENABLE=0`，因此 ARM/PWM/MOVE 均不能触发动作。

演练与手动 ARM 互斥。演练结束、中止或故障后需 RESET 才能重新开始或使用手动动作；运行期间须先 STOP 再 RESET。
DISARM 会同时中止正在运行/暂停的演练。模拟参数及实际执行之间尚未接通，详见 [演练说明](testing/无舵机演练使用说明.md)。

## 4. PWM 云台

TIMA1，两通道，32MHz 总线时钟分频到 1MHz，周期 20000 个计数，即 50Hz。PA15 为水平、PA16 为俯仰。上电配置定时器但停止计数，GPIO 输出低电平，只有手动测试解锁后才切换为 PWM 复用。

1500µs 只是常见的调试中值，不保证对应这两款未知型号舵机的 90°。实际波形、转向、脉宽范围和零点均待舵机到货后测量。
