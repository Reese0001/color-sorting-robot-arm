# 代码导航：按项目环节阅读

当前主控是 **TI MSPM0G3507**，视觉板是亚博 K230。整理包是当前工程的源码快照；主控 C 文件和 K230 Python 文件均保留原内容。旧 K230 自行驱动云台的脚本单独归档，不属于现行 MSPM0 驱动云台的方案。

| 环节 | 最重要的文件 | 作用 | 状态 |
|---|---|---|---|
| 1. 摄像头取图 | `vision/k230/camera_check.py` | 相机和显示自检 | 之前已验证画面；本次只收录 |
| 2. 红绿蓝阈值 | `vision/k230/auto_calibrate.py` | 采样并输出 LAB 阈值 | 待真实木块现场标定 |
| 3. 颜色与坐标 | `vision/k230/color_detection.py` | 三色检测、稳定判断、像素坐标、UART 数据帧 | 串口默认关闭；整机联调待做 |
| 4. 接收视觉数据 | `firmware/lib/k230_protocol/k230_protocol.c`、`.h` | 帧解析、校验、在线状态、候选颜色 | 电脑协议测试通过；真实 K230 链路待验收 |
| 5. 主控入口 | `firmware/src/main.c` | 初始化、主循环、串口命令、状态报告 | 板端 PING/STATUS 通过 |
| 6. 引脚与外设 | `firmware/src/board_mspm0.c`、`firmware/include/board.h` | 时钟、UART、收发缓冲、PWM 底层 | 调试 UART 已实测；PWM 波形未测 |
| 7. 全局参数 | `firmware/include/app_config.h` | 波特率、PWM 范围、动作/总线开关 | 两个输出开关均为 0 |
| 8. 抓取流程 | `firmware/src/robot_workflow.c`、`robot_console.c` | 七步流程、暂停/继续/停止、模拟完成与超时 | 红左、绿中、蓝右板端模拟通过 |
| 9. 关节与姿态 | `firmware/src/robot_config.c`、`firmware/include/robot_config.h` | 舵机 ID、方向、零位、限位、姿态结构及检查 | 参数保留未标定状态；不能直接驱动整臂 |
| 10. 舵机通信 | `firmware/lib/hiwonder_bus/hiwonder_bus.c`、`.h` | 幻尔传统总线帧、校验、位置请求/响应 | 编码解析测试通过；BusLinker/舵机实测待做 |
| 11. 下载程序 | `tools/bsl_direct.py`、`serial_bridge.ps1`、`hex_image.py` | Windows USB BSL 烧录和校验 | 本板 MAIN 已完成 CRC 与启动验证 |
| 12. 板端复测 | `tools/check_bench_uart.ps1`、`check_bench_flow.ps1` | 检查串口与三色模拟 | 已通过；运行时需要主控 USB |
| 13. 无板演练 | `tools/robot_sim.py`、`robot_sim_backend.c`、`build_robot_sim.py` | Python 界面调用与板端共用的 C 流程 | 电脑上运行，不打开串口 |
| 14. 自动测试 | `tests/test_protocols.c`、`test_workflow.c`、`test_bsl_direct.py` | 协议、状态机、下载器的离线检查 | `tools/run_pc_checks.py` 统一运行 |
| 15. 模拟视觉发送 | `tools/k230_sender.py` | 电脑生成测试帧；可经额外 USB-TTL 发给主控 | 不指定 `--port` 时只打印，不发串口 |

## 主控阅读顺序

先看 `main.c` 了解入口，再看 `app_config.h` 和 `board_mspm0.c` 找参数与引脚；随后看 `k230_protocol.c` 理解数据来源、`robot_workflow.c` 理解流程、`robot_config.c` 理解待标定参数，最后看 `hiwonder_bus.c` 理解底层报文。

这些 `.c/.h` 会一起编译进 MSPM0 固件，不是分别双击运行的程序。`robot_workflow.c` 也用于电脑模拟器，保证两端共用同一套流程逻辑。

## 当前没有完成的环节

七步流程的完成信号目前由软件模拟，不是舵机反馈。自动扫描、相机坐标到机械臂坐标的换算、逆运动学、实际动作执行及到位确认尚未完成。`pan/tilt` 不是已测量的关节角，不能把图像像素直接当成舵机角度。

整理包中 `vision/k230/archive_k230_pwm/` 仅保留早期试验代码。这两个脚本会配置 K230 的 PWM，旧扫描脚本还使用 `@C` 旧协议；当前主线采用 `@T` 协议、MSPM0 控制云台，不能混用。

接口以 [通信协议](通信协议.md) 和 [接线说明](../hardware/wiring/MSPM0G3507接线.md) 为准。
